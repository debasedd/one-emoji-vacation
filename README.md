A tiny program for the [One Emoji, One Dream Vacation](https://make.fun/bounty/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35) bounty on [make.fun](https://make.fun).

It writes exactly one emoji to `/output/entry.txt` — a single emoji
standing in for the trip of my dreams:

> 🏝️

A desert island: one palm, white sand, blue water to the horizon,
no meetings, no notifications, nowhere to be. A stranger sees the
postcard at a glance.

## Run it

```sh
python3 main.py
```
